FILES FOLDER
============
Put downloadable files here:

  cv.pdf      your CV (the CV page shows a download button automatically once this file exists)
  *.csv       datasets you want people to download (see data/datasets.js)
  *.pdf       reports or posters you link from a project

The two sample CSV files in this folder belong to the illustrative datasets on
the Data page. They contain calculated values, not measurements. Delete them
when you remove those datasets.

Do not put private documents here: everything in this repository is public.
